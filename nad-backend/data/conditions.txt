# spelling that ends up in the transcript. Multi-word names are fine (matched as a phrase,
# up to MAX_WINDOW words). Add whatever your domain needs.

# Chosen for how badly a transducer mangles them, not for how common they are: long Greek
# and Latin compounds ("gastroesophageal", "thrombocytopenia") are what an ASR with no
# medical vocabulary splits into English-looking pieces. Everyday one-word conditions that
# a general model already gets right ("cough", "rash", "fever") are deliberately absent --
# they add fuzzy attractors that could capture ordinary speech and buy nothing.
#
# Anything added here must survive test_drug_lexicon.py::test_ordinary_speech_is_untouched.
# A near-miss against plain English corrupts the transcript, which is worse than failing to
# correct a term: see the "an email"/anemia case that set MIN_FUZZY_LEN.
